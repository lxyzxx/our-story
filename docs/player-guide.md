# 放映与内容说明

Phase 2 的工作台视觉已由用户确认，Phase 3 延续该方向。这里说明正式放映部分，Phase 4 生日终幕也已接入，管理后台与持久化属于 Phase 5。

## 放映路径

打开胶卷后点击“开始放映”。首次观看按有照片的章节顺序进行；其他卷可预览，待前面的章节结束后开始放映。空卷保留展示但不阻塞有内容章节的放映顺序。最后一张结束后进入字幕卡，只有主动点击才进入下一卷。全部有内容的章节完成后，片头提供完整重看与档案馆入口，之后可自由选择。

## 阅读与播放

每张默认 8 秒，在 `archive.json` 的 `player.frameSeconds` 配置（有效范围 4–60 秒）。等待图片加载时不计时；暂停保留当前帧的已用时间。页面进入后台、展开音乐设置、打开故事都会暂停计时。前后台切换后恢复原有播放意图。

故事阅读先暂停，收起后仍暂停，需要点击“继续放映”。故事保留换行和分段；短文可直接作为字幕，长文显示独立纸面阅读层。日期与地点可选。当前首段是明确标识的阅读排版说明，**不是私人回忆**。

上一张/下一张、方向键、照片选择、手机左右滑动均可换片。选择跳转会暂停。点击照片或右上图标隐藏/显示控件。空格在非原生交互控件上切换播放；按钮、选择框与音量输入保留原生键盘行为。Escape 优先收起故事，再返回工作台。旋转不会重置照片。

主照片使用 `object-fit: contain`；轻微镜头运动预留边距。底片最多绘制六张不同缩略图的重复轨道，主银幕只渲染当前照片；不同时加载 50 张原图。演示竖图来自单独的图库衍生版本，播放器没有裁切真实用户图片。

## 音乐

`music.opening`、`music.archive` 配置片头与常规音轨；章节的 `music` 可覆盖常规音轨。`music.finale` 用于生日终幕。只填写你有权使用的同源或允许跨域访问的音源。

第一次用户点击时同步请求播放，之后使用同一个原生音频对象，在切换时先淡出再淡入，避免重复实例。音量与静音跨场景保留；无音源、被浏览器拦截、加载失败都不会阻止放映。浏览器拒绝时可手动重试。iPhone 的自动播放权限与音量行为仍需真机验收，不能由 Chromium 测试推定。

## 进度与内容持久化的区别

浏览器只保存 `our-story:progress:v1`：完成过的章节 ID、最近的章节与帧 key。禁用存储时使用本次会话的内存降级。新增/移除章节按现有内容重新计算解锁；重要照片与故事不写进 localStorage。

正式数据库/存储尚未接入。当前内容来自源码 JSON，或者服务器环境变量 `ARCHIVE_CONTENT_FILE` 指向的 JSON 文件。该变量只从部署环境读取，不接受 URL 参数；可用于本地内容维护和隔离测试。指定文件时应使用相同的 ArchiveContent 结构，保留源码与媒体备份。服务端每次请求读取，首页为动态渲染。

## 隔离测试

`tests/fixtures/archive-50.json` 为 50 帧测试样本，包含重复演示照片、空章节和测试音源路径，不能发布为正式内容。测试中的短正弦波只在 Playwright 路由中临时生成，不存在于公开素材目录。

先运行 `npm run build`，再分别启动正常预览和测试实例：

```bash
PREMIERE_PREVIEW=1 npx next start --hostname 127.0.0.1 --port 3002
ARCHIVE_CONTENT_FILE="$PWD/tests/fixtures/archive-50.json" npx next start --hostname 127.0.0.1 --port 3004
```

第二个实例单独运行测试：

```bash
ARCHIVE_FIXTURE_URL=http://localhost:3004 npm run test:e2e -- --project=content-fixture
```

测试完成应停掉 3004 实例。正常预览不设置 `ARCHIVE_CONTENT_FILE`，不会混入测试音频或 50 帧数据。

## Phase 4 接入

最后一个有照片的章节结束后进入生日终幕，信件阅读和片尾都由用户主动推进；完成后可以重读生日信。当前默认首映门禁已开启，正常 3001 在北京时间 2027-02-07 00:00 前只显示倒计时。影片回归与截图的默认服务现为作者预览 3002；上方命令使用 `PREMIERE_PREVIEW=1` 且仅绑定本机。具体步骤见 [premiere-guide.md](premiere-guide.md)。
