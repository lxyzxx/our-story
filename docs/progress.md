## Phase 3 实现

- 胶卷展开后由用户主动开始放映。照片完整 `contain` 呈现，横图/竖图有独立构图，保留镜头运动的边距；图像先出现，文字稍后显现。
- 默认每张 8 秒，可配置 4–60 秒。上一张/下一张、暂停/继续、计数、照片选择、方向键与真实浏览器触摸滑动都已接入。
- 暂停保留已用时；等图加载、页面后台、音乐设置、阅读故事都停表。阅读层是独立纸面，收起后继续保持暂停，不自动换片。
- 每章结束进入字幕卡，等用户主动进入下一幕。有照片的章节按顺序引导，空卷可预览并跳过其放映顺序；全部看完解锁自由重访与完整重看。
- 浏览器只保存完成的章节 ID 和最近帧，禁止存储时退回会话内存。照片与故事始终来自服务端内容源，重要内容不依赖 localStorage。
- 同一原生 Audio 跨场景复用，点击时请求播放、先淡出再换曲淡入；静音/音量跨场景保留。片头、展开、放映、阅读与章节字幕都有可访问的控制入口；无源/失败/浏览器阻止不影响主流程。
- 底片只载入当前附近最多六张不同缩略图；主银幕仅渲染当前照片。无图卷不会出现 NaN，也不会阻塞其他有内容章节。
- 服务端支持 `ARCHIVE_CONTENT_FILE` 读取同结构本地 JSON，首页动态渲染；测试文件和正常预览隔离。没有因此宣称已经具备后台/对象存储。
