# 胶片档案室设计与实现说明

本文件解释 Phase 2 工作台与 Phase 3 放映室的实际视觉和交互。规范色彩、字体角色、形状、间距和组件 token 见 [DESIGN.md](../DESIGN.md)；既有阴影、运动、断点与组件预览见 [.impeccable/design.json](../.impeccable/design.json)。Phase 3 的局部扩展和规范覆盖范围见 [screening-design.md](../.impeccable/screening-design.md)。本文不建立第二套全局 token。

## 视觉方向

视觉世界已由用户确定：电影感复古酒红工作台、炭黑器材、暖金与奶油文字、真实 35 mm 胶卷。台面即场景，胶卷即入口。纸条、松散照片、底片和小工具建立私人收藏氛围，不能演变成卡片列表；不加入粉色、爱心或卡通情侣元素。

当前风景照片来自 Unsplash，均为演示。第一段长文明确写着「演示排版 · 这不是我们的私人回忆」，只是说明阅读布局与交互；其余空故事保留等待本人填写的提示。不得补写私人的时间、地点、姓名或生日信。图片、字体和颗粒的来源与许可见 [assets.md](assets.md)。参考视频仅用于研究，不作为交付素材。

## 字体与信息层级

`src/app/layout.tsx` 通过 `next/font/local` 加载 Bodoni Moda 与 Manrope。前者负责片头、工作台标题、胶卷名称和斜体编号；后者负责提示、按钮和器材小字。中文回退到系统字体。

片头、工作台与展开标题分别对应规范的 display、headline、title。工作台正文基准为 body，器材刻字另按物件尺寸缩放。小字是铭牌，不作为长文阅读字号。Phase 3 在独立纸面上建立故事正文样式，详见下文；中文仍使用系统字体，不宣称已打包中文字体。

## 真实胶卷的分层

`FilmRoll` 使用 CSS 实体结构，非平面图片：

1. 胶尾带上下齿孔，位于筒体后方。
2. 中轴从左侧略微探出。
3. 圆柱筒身以纵向暗部、高光和底边形成曲面。
4. 纸标包裹在筒体内，使用微斜切、边缘暗部和颗粒。
5. 两侧金属圈遮住纸标，右端盖补出立体厚度。
6. 统一右下落影连接台面，不能为每层添加独立悬浮方向。

奶油、橄榄、铁锈与炭黑标识沿用相同结构。`--roll-size` 同时控制外壳、铭牌与比例，响应式优先调整尺寸和摆放，不改变物理关系。

## 交互、运动与清理

鼠标悬停轻抬与轻转；键盘聚焦显示展开动作；粗指针点击先选中，再点击展开。入口会保存胶卷的实际位置，展开层据此抬升直立胶卷，然后拉出底片、放下观片器。

`src/lib/motion.ts` 定义 hover、lift、unroll、settle 与默认 ease。当前 `FilmUnroll` 仅复用 lift / unroll，实际缓动均是 `power3.inOut`；观片器使用单独的 `0.7s power3.out`。hover、settle 和默认 ease 是已声明但未被消费的常量；CSS 悬停与场景淡入另有真实时长。扩展 token 逐项记录了区别，不能把定义值误写成运行值。

片头 tween 在卸载时 kill；工作台使用 GSAP matchMedia 和 context 并在卸载时 revert；展开时间线同样通过 context revert 回收。展开、放映与章间层共用 `useScreeningDialog`：保存并恢复 body 的内联滚动样式及原滚动位置，卸载时移除键盘监听；退出后恢复胶卷入口焦点，底层工作台在选择章节时 inert。Tab 在当前层可见且可交互的按钮、输入框和选择框之间循环；音乐控件属于当前层，不放在焦点范围外。

`prefers-reduced-motion` 跳过 JS 入场与展开，禁用鼠标视差，把 CSS 动画与过渡压缩到几乎瞬时。放映照片缓移、照片/字幕淡入、阅读层和章间淡入另被明确禁用；放映计时与手动操作保持可用。颗粒是静态背景，最终透明度为（0.035）。音乐由自己的声音控制决定，不随视觉减少动态效果开关自动静音；默认演示内容尚未配置音乐文件。

## 照片与观片器

底片缩略图使用棕褐负片滤色和 `object-fit: cover`，传达胶片材质；主照片使用 `object-fit: contain`，在机壳内完整呈现。预览轨道最多显示六张附近照片，翻页仍可到达整卷照片。支持点击底片画幅、翻页按钮、方向键及水平触摸滑动（45px 阈值）。Escape 返回工作台。原生音量输入框和照片选择框保留自己的方向键行为。

观片器是深橄榄机壳、黄铜光孔、底座、侧拨杆与红色旋钮的组合；红色仅属于器材零件，不扩展为界面强调色。按钮与页眉保持低视觉重量，避免抢走照片。

展开完成后才启用「开始放映」。首次按章节顺序解锁正式放映，未解锁的胶卷仍可预览；全部看完后允许自由重访。展开动画和照片预览不会自动替用户启动放映。

## Phase 3：放映银幕

`MemoryPlayer` 将物件式观片器过渡到炭墨银幕。照片是主角；章节页眉、标题、可选日期地点、故事入口与播放操作都在照片外。银幕保留细黄铜上下边与极小的画幅编号，继续使用既有字体与暖中性色。

| 场景 | 放映布局 | 故事阅读布局 |
| --- | --- | --- |
| 桌面 | 页眉（96px），照片填充中间弹性区域；下方标题与摘要两列，播放控件居中，照片选择靠右 | 右侧纸面，宽度不超过（640px）；左侧保留遮暗的暂停照片 |
| 手机横屏 | 页眉（50px），银幕优先；标题、故事入口、播放和选择压为底部一行，隐藏摘要和播放按钮文字 | 纸面不超过（600px）且不超过视口（85%）；文章独立滚动，页眉与返回入口留在纸面上 |
| 手机竖屏 | 页眉（88px），照片区域至少（220px）；标题、摘要与故事入口、播放控件、照片选择纵向排列 | 窄手机纸面占满宽度，上限仍为（640px）；正文滚动，底部保留「收起故事」与安全区留白 |

照片均以 `object-fit: contain` 呈现，竖幅留左右黑边，横幅在狭长竖屏留上下黑边。默认先留出约（3%–4%）内边，再以（1 → 1.025）缩放和（−0.3% → 0.3%）水平位移缓慢运动；此运动不靠裁切关键内容制造效果。换片照片淡入（0.8s），字幕淡入（0.7s，延迟 0.6s）。暂停时缓移暂停，减少动态效果时关闭上述动画。

单张时长来自内容配置，默认（8s），限制在（4–60s）。图片加载完成才计时；手动暂停、阅读故事、页面进入后台、打开音乐设置都会暂停计时，回到可播放状态后接着累计。照片加载失败显示提示并暂停，仍可手动换片。

上一张、下一张、暂停/继续、计数与原生照片选择器均可操作。左右方向键换片，空格切换暂停；焦点在原生输入框/选择框或正在使用音乐设置时保留原生操作。点击照片或角落图标可隐藏/显示下方字幕与控件，隐藏后仍保留恢复入口。触摸换片要求水平距离超过（50px）且明显大于垂直距离，避免妨碍纵向滚动。直接选择照片会暂停放映。

## Phase 3：纸面故事

`MemoryStory` 使用暖旧纸背景（`#e4dac7`）与深褐正文（`#3b302a`）。这是放映室的局部材料色，不替换全局奶油文字或炭墨背景。标题沿用 Bodoni Moda 与中文后备；正文沿用 Manrope 与系统中文后备，桌面/竖屏（15px，行高 2.15 / 2.1），横屏（14px，行高 2）。段落之间留白，最大行长（65ch），引句使用斜体衬线。

短故事（不超过 80 字）可直接作为照片外摘要；长故事使用引句或明确的演示提示，引导进入完整阅读。正文按空行分段，不截断全文；没有故事时显示等待本人填写的提示。日期与地点仅在数据存在时显示。

打开故事会暂停当前照片和计时，底层播放器 inert，焦点移到关闭按钮。阅读层沿用当前对话框的焦点约束，音乐按钮仍在纸面页眉内可达。Escape 或「收起故事」先关闭阅读层，并将焦点还给故事入口；放映继续保持暂停，用户按「继续放映」才恢复。

## Phase 3：章间停顿与重访

最后一张结束后，`ChapterTransition` 显示独立字幕卡：炭墨与低亮酒红渐变、细黄铜横线、斜体衬线标题，沿用片头的轻量细线按钮。此处等待用户主动点击「进入下一幕」，再进入下一卷的展开预览；下一卷仍需点击「开始放映」。不会倒计时跳章。

全部有照片的章节看完后，字幕卡提供返回档案馆；片头增加完整重放与直接进入档案馆，胶卷旁显示已看状态。这是 Phase 3 的放映完成态，生日终章、生日信和字幕演职员表仍待后续阶段。

## Phase 3：共享声音控制与本地记录

片头、工作台、展开、播放器、故事纸面和章间卡共享同一音乐控制器。播放启动来自用户开始操作；来源按片头音乐 → 档案馆音乐、章节音乐 → 档案馆音乐回退。切换来源先淡出（0.4s），再淡入（1.25s）；曲目循环，静音偏好会在首次播放前写入音频元素。默认音量（45%），面板可调整音量、静音和失败重试。故事阅读或照片暂停不自动暂停背景音乐，用户可随时自行静音。

音乐未配置时明确显示 SOUND OFF；浏览器阻止播放或加载失败时提供重试，安静浏览仍可继续。音乐面板 Escape 先关闭面板并归还设置按钮焦点。演示配置没有商业音乐，自动化音频是测试临时素材，不是交付配乐。

`useArchiveProgress` 只将已看章节与最后画幅写入浏览器本地记录，用于顺序解锁、续看与重访；存储不可用时退回当前页面内存。此记录不编辑照片、故事或章节，也不是账号同步或 Supabase 内容持久化。音量与静音目前仅保留在当前挂载的控制器中，不宣称刷新后保存。

## 视觉核对与范围

Phase 2 工作台已获用户接受，Phase 3 继续沿用其视觉世界。本次文档核对了 `docs/screenshots/phase3/` 的桌面/手机横屏/手机竖屏播放器和故事截图，以及桌面竖幅照片截图；三种构图均保留完整照片与可达阅读入口。截图是浏览器构图证据，不能替代真实设备、音频听感或用户最终视觉验收。

自动化与构建结果以当前[进度记录](progress.md)、[收尾评审](../.impeccable/review/finish-review.md)及测试报告为准，不沿用 Phase 2 的测试数量作为 Phase 3 结论。当前范围不包括真实私人照片与故事、生日终章、管理后台、账号认证、Supabase 持久化或公开部署。素材许可记录、功能检查与视觉验收分别记录；本次文档没有修改交付图片或规范 token。
