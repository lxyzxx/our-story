# 参考视频分析

## 素材与方法

原始参考视频与研究抽帧仅在本地保留，不随 Git 仓库提交。克隆后运行网站不需要这些文件；若要复现分析，请将参考视频放回下述路径，再执行文末抽帧命令。

- 文件：`references/电子负片.mp4`，155.69 秒，720×544，HEVC，约 20 fps（容器标称 30 fps）；AAC 单声道。
- ffprobe 读取参数；ffmpeg 每 3 秒、每 10 秒采样，并对 39–42 秒以 4 fps 观察过渡。截图只作内部研究，不用于网站视觉素材。
- [全片总览](reference-frames/overview.jpg)、[前 45 秒](reference-frames/contact-sheet.jpg)、[39–42 秒连续动作](reference-frames/transition.jpg)。总览每格时间依次为 0、10……150 秒；前 45 秒每格为 0、3……45 秒。

## 可见构图与交互

| 时间（约） | 可以观察到的画面 | 本项目提炼 |
| --- | --- | --- |
| 0–3 s | 信封、纸信退场，酒红台面与四卷胶卷出现 | 独立黑场片头；用户主动开始后点亮工作台 |
| 3–6 s | 奶油、绿、橙、黑四卷；左右错落、倾斜，鼠标靠近 | 物件构图与不同色标；鼠标轻抬、触摸二次打开 |
| 6–18 s | 胶卷到前景左侧并直立；橙棕负片横向展开，照片顺序出现 | 保持胶卷位置连续；变换与底片轴向展开联动 |
| 21–33 s | 第二卷展开；选中的底片放大到前景，背后暖光 | 前景观片器承接选择；照片保持原比例 |
| 39–42 s | 绿色观片器入场、胶卷向左前移动、画面靠近；红色侧杆出现 | 独立分层观片器、黄铜镜框、红色拨杆细节 |
| 40–60 s | 观片器逐张换片；底片一直保留在后方 | 原型用手动按钮、键盘与滑动检查照片位置，不提前制作完整播放器 |
| 60–80 s | 接触印样、笔、画圈的选片纸张；回到四卷工作台 | 辅助纸张、相片、铅笔表达私人收藏环境 |
| 90–110 s | 银色冲洗盘、夹子悬挂照片、翻出手写故事 | 后续电影叙事可用阅读层承接长文；本轮不复制冲洗场景 |
| 150 s | 照片墙收束画面 | 生日终幕另行设计，待 Phase 4 |

## 材质、空间与色彩

参考整体较暗，上半部接近黑色，下半部饱和酒红；暖光从中上方落在标签和桌面，阴影向右下延伸。胶卷端盖有金属环、中央轴芯，筒身是沿纵深变暗的曲面，标签的边缘进入阴影。底片为通透橙棕、上下齿孔、细小边码。绿色观片器具有黄铜边、深色遮光窗与红色侧杆。

本站使用较柔和的 `#472B32` 台面，奶油白文字与暖金边缘，降低原片强烈红色与高对比阴影带来的疲劳。桌面不是四张信息卡片；胶卷自然错位，照片、纸条、放大镜与铅笔退居边缘。标题使用本地 Bodoni Moda，界面使用本地 Manrope 与中文系统字体。

## 节奏与技术替代

录屏分辨率、重编码、剪辑与鼠标采样使原始 hover 位移、真实 3D 模型、光源算法、曲线与严格时长无法确认；**以下是设计参数，不是从源代码还原的数值**：

- Hover 220 ms，`cubic-bezier(.16,1,.3,1)`；轻微上提与转角。
- 胶卷靠近并直立 550 ms，`power3.inOut`；起点来自实际物件 DOMRect。
- 底片展开 1200 ms，左侧固定轴心，`power3.inOut`；随后照片依次显现。
- 观片器落位 700 ms；标题/说明晚于主体出现。
- GSAP context 卸载时 revert；状态只允许一卷处于展开场景，退出无需等动画结束。
- 桌面 CSS 物件与少量静态颗粒代替未知的原始 3D 实现；本轮不引入 WebGL。

这些替代保留了参考的构图、物件与动作逻辑，不能声称像素级或物理级还原。全片并没有证明后台、音乐淡入、完整移动交互或生日信已经存在；这些来自本项目需求。

## 复现抽帧

```bash
ffprobe -v quiet -show_format -show_streams -of json references/电子负片.mp4
ffmpeg -i references/电子负片.mp4 -vf 'fps=1/10,scale=540:-1,tile=4x4' -frames:v 1 docs/reference-frames/overview.jpg
ffmpeg -ss 39 -i references/电子负片.mp4 -vf 'fps=4,scale=540:-1,tile=4x3' -frames:v 1 docs/reference-frames/transition.jpg
```
