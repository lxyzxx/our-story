# Phase 3 放映室：既有视觉世界的扩展

## Overview

本说明依据当前源码与 `docs/screenshots/phase3/` 编写，落实 [screening-contract.md](screening-contract.md) 的「照片完整呈现，故事和控制退到照片之外」。Phase 2 工作台的视觉方向已获接受，继续采用「深夜的私人胶片工作台」。不替换 [DESIGN.md](../DESIGN.md) 与 [design.json](design.json) 的规范 token，也不重做胶卷和器材。

规范文件仍是 Phase 2 快照：其中「没有长文阅读样式」「声音仅为未配置提示」与横屏预览按钮（38px）的描述不能覆盖本次新增行为；当前分别已有纸面故事、可配置共享音频控制、横屏预览按钮（44px）的局部覆盖。sidecar 尚未收录放映室、阅读纸面、音乐面板、章间字幕卡和（1000px）放映布局规则。这些是已知文档覆盖差异，保留原文件并在此记录，不将其静默改成新的全局规范。

## Colors

银幕继承炭墨、奶油与黄铜；照片内侧以更暗底色承接横竖幅黑边。暖纸阅读使用源码中的局部旧纸色（`#e4dac7`）、深褐字（`#3b302a`）与褐色辅助信息；它们附着于阅读纸张，不推广为工作台按钮或页面背景。章间卡沿用低亮酒红到炭墨的径向渐变。

## Typography

沿用本地 Bodoni Moda / Manrope 与系统中文后备。桌面故事标题（34px），竖屏（29px），低矮横屏（25px）；故事正文桌面/竖屏（15px），横屏（14px），行高分别为（2.15 / 2.1 / 2），最大行长（65ch）。段落按空行分组，正文区域独立滚动；日期与地点仅在数据存在时出现。器材刻字的微小字号仍只属于器材。

演示长文明确说明其为排版说明，不编造私人回忆。空故事提供待填写提示；照片外只展示短故事、引句或演示提示，完整文章保留在阅读层。

## Layout

- 桌面：页眉（96px），中部弹性银幕，下方两列信息与播放操作。纸面从右侧覆盖，宽度不超过（640px），暂停照片仍在遮暗背景中可见。
- 手机横屏：沿用（max-height: 550px）与横屏条件，页眉（50px），照片优先，标题、阅读、播放与选择压在底部一行。阅读纸面宽度取（600px）与视口（85%）中较小值。
- 手机竖屏：沿用（max-width: 700px）与竖屏条件，页眉（88px），照片区域最小（220px），下方操作分行；窄手机阅读纸面铺满宽度，上限仍为（640px）。长文只滚动文章区域，收起入口与安全区留白保留。
- 中等宽度：放映室（max-width: 1000px）时将照片选择器放回普通布局，收紧列间距；这是放映室局部条件，不替代工作台既有中宽断点。

照片采用 `contain`，横竖幅都保留全幅和必要黑边。图片容器预留内边（约 3%–4%），缓移为（1 → 1.025）缩放与（−0.3% → 0.3%）水平位移；不将工作台底片的负片滤色带入主照片。

## Elevation & Depth

工作台仍使用共享光源与结构性物件投影。放映室以明暗分层代替额外器材堆叠；纸面侧影（`-15px 0 50px #0004`）只表达盖在暂停照片之上。音乐设置为小型暗色面板，不引入通用卡片系统。

## Shapes

银幕、照片选择器与纸面以直边为主，细线延续器材标记；播放圆按钮复用既有轮廓。横屏展开预览翻页按钮现为（44 × 44px）。其他小图标、设置入口和竖屏原生选择器各有实际尺寸，不宣称所有控件都已统一为同一触摸尺寸。

## Components

`FilmUnroll` 保留从真实入口位置抬升、展开底片与观片器落定的时间线。完成后启用「开始放映」；首次按顺序解锁放映，所有章节仍可预览。预览轨道只显示附近最多六张照片，翻页可遍历整卷。

`MemoryPlayer` 默认每张（8s），配置限制（4–60s），加载后才计时。手动暂停、故事阅读、后台页面和打开音乐设置均暂停累计。照片失败时显示提示并暂停。照片淡入（0.8s）；字幕淡入（0.7s，延迟 0.6s）。点击照片或角落入口隐藏/恢复下方操作，保留恢复入口。

左右方向键换片，空格暂停/继续；音乐设置打开时播放器快捷键停用，输入框和选择框保留原生按键。播放器触摸换片需水平位移超过（50px），并大于纵向位移的（1.3 倍）；展开预览为（45px）阈值。Tab 在当前对话框的可见交互元素之间循环，底层工作台 inert，退出恢复胶卷焦点和页面滚动位置。

`MemoryStory` 打开后将播放器 inert，焦点移到关闭按钮；纸面页眉内保留声音设置。关闭或 Escape 返回当前照片，焦点回到故事入口，放映仍暂停，等待用户主动继续。音乐面板自己的 Escape 先关闭面板。

`ChapterTransition` 在一卷结束后停下，等待点击「进入下一幕」进入下一卷展开，再由用户开始放映；末卷结束提供返回档案馆。章间卡使用（1s）淡入，不设置自动跳转。当前完成态不代表生日终章已实现。

`MusicPlayer` 在片头、工作台、展开、放映、阅读与章间复用同一控制器。用户开始后才激活；支持静音、音量、播放受阻/失败重试，以及换源淡出（0.4s）与淡入（1.25s）。激活前设置的静音会先写入音频元素。照片暂停与阅读不自动停止音乐。默认内容未配置音源，显示真实缺省状态，测试音频不作为配乐发布。

`prefers-reduced-motion` 禁用照片缓移、照片/字幕/纸面/章间淡入，跳过既有 JS 入场和展开；计时、阅读与导航仍可使用。声音偏好独立于此视觉设置。

浏览器本地记录只保存已看章节和续看画幅，存储不可用时退回当前页面内存；这是观影记录，不是内容持久化。音量和静音仅为当前控制器状态。照片、故事和章节的后台管理、账号与 Supabase 存储尚待后续阶段。

## Do's and Don'ts

- Do 保持照片全幅、留黑边、控制在照片外；同时检查横幅和竖幅文件。
- Do 将阅读和章间停顿交给用户，收起故事后等待主动继续。
- Do 让声音控制在当前层内可见、可聚焦；保留原生范围输入与选择器的按键。
- Do 使用真实数据里的可选日期地点，保留演示素材与排版说明标识。
- Don't 将纸面局部色和布局改写成第二套全局 token，或据此重做已确认的工作台。
- Don't 将浏览器截图、测试通过或本地观影记录写成真实设备验收、正式私人内容或云端存储完成。

核对依据：`MemoryPlayer`、`MemoryStory`、`ChapterTransition`、`FilmUnroll`、`MusicPlayer`、`useMusicPlayer`、`useScreeningDialog`、`FilmArchive`、`useArchiveProgress`，以及 `globals.css` 的 Phase 3 段；截图为桌面/手机横屏/手机竖屏的播放器与故事，以及桌面竖幅照片。测试与构建状态由 [progress.md](../docs/progress.md) 记录，本说明不重复未经确认的最终测试数量。素材来源见 [assets.md](../docs/assets.md)。
